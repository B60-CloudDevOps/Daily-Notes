# 📘 Networking & Web Basics Notes

## 🧠 Cache

A **cache** is a temporary storage mechanism used to store frequently accessed data for faster retrieval.

- Helps improve performance and reduce latency
- Avoids repeated computation or network calls

### Cache Outcomes
- **Cache Hit** ✅  
  When the requested data is found in the cache

- **Cache Miss** ❌  
  When the data is not found in the cache and must be fetched from the original source

## 🌐 HTTP Status Codes

HTTP response status codes indicate whether a specific request was successfully completed.

They are grouped into five categories:

| Range | Category | Meaning |
|------|--------|--------|
| **100–199** | Informational | Request received, continuing process |
| **200–299** | Success | Request successfully completed |
| **300–399** | Redirection | Further action needed (redirects) |
| **400–499** | Client Errors | Issue with request from client side |
| **500–599** | Server Errors | Server failed to fulfill valid request |

## 🌍 Private IP vs Public IP

### Private IP Address
- Used within a local network (home, office)
- Not accessible directly over the internet
- Example ranges:
  - 192.168.x.x
  - 10.x.x.x
  - 172.16.x.x – 172.31.x.x

### Public IP Address
- Assigned by ISP (Internet Service Provider)
- Accessible over the internet
- Used to identify your network globally
